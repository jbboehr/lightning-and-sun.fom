# Project planning

Read [docs/planning.md](docs/planning.md) for current status, priorities and scope.
Update that overview and its linked plan when authorized work changes a milestone,
blocker, acceptance result or scope. Keep detailed evidence in the development
document that owns it and link it from the overview.

The overview holds current status, remaining work and standing decisions, not
history. Record feedback quotes, qualifications and chronology only in the owning
record. When a slice closes, reduce its overview entry to one dated line with a
link in the same commit, and update the remaining-work table.

Proposed work is not approved implementation. Preserve recorded art approvals and
verification limits; passing automated checks does not establish visual acceptance.
